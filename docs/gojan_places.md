# 고잔동 장소 목록 (페이즈 1)

장소 데이터는 `lib/features/map/gojan_area.dart` 한 파일에 있습니다.
좌표는 공개 자료로 찾은 대략적인 값이라, **실제 휴대폰으로 지도를 띄워 확인한 뒤 고쳐야 합니다.**

| 이세계 이름 | 실제 장소 | 상태 | 좌표 출처 |
| --- | --- | --- | --- |
| 중앙 미궁 입구 | 안산 중앙역 | 사용 | 역 문서 좌표 (37.31596, 126.83864) |
| 작은 미궁 입구 | 고잔역 | 사용 | **추정값**: 중앙역에서 서쪽 1.4km |
| 정령의 호수 | 안산호수공원 | 사용 | 관광 정보 좌표 (37.30062, 126.82355). 자료마다 주소 표기가 달라 확인 필요 |
| 음유시인의 극장 | 안산문화예술의전당 | **보류** | 화랑유원지와 붙어 있음 (37.32128, 126.82228) |
| 여관 | 카페 | 비어 있음 | 직접 골라 추가 |
| 잡화상 | 편의점 | 비어 있음 | 직접 골라 추가 |

## 제외 구역

| 이름 | 처리 |
| --- | --- |
| 화랑유원지 · 4·16 생명안전공원 일대 (초지동) | 반경 700m 원으로 넉넉하게 제외. 실제 경계 확인 후 조정 |

제외 구역 안에서는 장소 방문, 몬스터, 전투, 이벤트가 일어나지 않습니다. 안개는 걷힙니다.
테스트(`test/exploration_test.dart`)가 "제외 구역 안에 장소를 두지 않는다"를 검사합니다.

## 장소 추가 방법

`gojan_area.dart` 의 `places` 목록에 아래 형식으로 넣습니다.

```dart
GamePlace(
  id: 'inn_001',            // 겹치지 않는 영문 id
  name: '휴식의 여관',        // 이세계 이름
  realName: '카페 이름',      // 실제 이름 (화면에는 방문 후에만 보임)
  kind: PlaceKind.inn,
  point: GeoPoint(37.3160, 126.8380),
),
```
