## 판단

1. **보통 유형은 목표대로입니다.** Lv.13, 하루 207. 그대로 둡니다.
2. **적게 걷는 사람은 목표보다 느립니다.** 하루 3,000~4,500보면 열쇠가 하루 1개라 던전이 1번뿐입니다. 걸음 목표를 사람마다 맞췄는데, 열쇠는 2,500보 고정이라 목표를 낮춘 효과가 던전에는 닿지 않습니다.
3. **많이 걷는 사람은 보통의 1.8배 빠릅니다.** 하루 열쇠 4개 상한이 이미 있어 걸음만으로 더 벌어지지는 않습니다.
4. **던전이 너무 쉽습니다.** 세 유형 모두 89번 중 89번 클리어했고, 스킬을 안 써도 같았습니다. 생활로 스탯이 기준보다 조금 더 빨리 올라서, 몬스터가 상대적으로 약해졌습니다. 지금은 '불씨의 일격' 버튼이 승패에 영향이 없습니다.
