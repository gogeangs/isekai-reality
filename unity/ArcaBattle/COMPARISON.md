# Unity 로 옮기면? — 좋은 점 · 어려운 점 · 걸리는 시간

> 이 시험판(전투 한 장면)을 만들며 본 것과 지금 저장소(Flutter, Dart 272파일 · 약 11만 줄)를 바탕으로 정리했습니다.
> 움직임이 「눈으로 봐서」 더 나은지는 대표님이 Unity 에서 직접 재생해 보고 판단해 주세요.

## 좋은 점 (전투 · 연출)

- **그림 움직임 도구가 기본으로 있음**: 칸 그림 재생, 기준점(발 바닥) 고정, 화면 멈춤(히트스톱), 카메라 흔들림을 코드 몇 줄로 처리. Flutter 는 이걸 위젯 겹치기와 계산으로 직접 만들어야 했음
- **셰이더(그림을 그리는 작은 프로그램)를 마음껏 씀**: 번쩍임 · 살랑임 · 사라짐 · 빛남 같은 효과를 그림마다 따로 걸 수 있음. 이번 시험의 머리카락 · 망토 살랑임이 그 예
- **파티클(작은 입자 효과) · 빛 · 후처리**: 불꽃 · 먼지 · 빛 번짐(Bloom)을 에디터에서 눈으로 보며 만듦 (URP 2D 기본 기능)
- **뼈대 애니메이션 길이 열림**: 2D Animation 패키지로 몸을 부위별로 나눈 그림(저장소의 `rig/` 그림처럼)에 뼈를 넣으면 숨쉬기 · 머리카락 · 망토를 자연스럽게 움직일 수 있음
- **재생 중에 숫자를 바로 고쳐 보기**: 배치 · 속도 · 흔들림을 Inspector 에서 바꾸면 즉시 반영 → 연출 다듬는 속도가 빠름
- **틀이 고정된 화면(전투 무대)** 은 GPU 가 한 번에 그려서 프레임이 안정적

## 어려운 점

- **앱 기능 대부분이 Unity 에 맞는 부품이 없음** (지금 쓰는 것 기준)
  - 네이버 지도(`flutter_naver_map`): Unity 용 공식 SDK 없음 → 지도 화면을 새로 만들어야 함 (가장 큰 걸림돌)
  - 걸음 수(Health), 카메라 + 얼굴 인식(ML Kit), Snap Camera Kit, 알림, Google 로그인: Unity 에서는 각각 따로 연결 코드(네이티브 플러그인)가 필요
  - Firebase · AdMob 은 Unity SDK 가 있어 옮길 수 있음
- **글 · 목록 · 메뉴가 많은 화면은 Flutter 가 훨씬 편함**: 마을 · 도감 · 우편 · 설정 같은 화면을 Unity UI 로 다시 만들면 손이 많이 감
- **한글 글꼴**: Unity 의 고급 글자(TextMeshPro)는 한글 1만 자 넘는 글자를 그림판으로 미리 굽거나 실시간으로 굽는 관리가 필요 (이번 시험은 단순한 기본 글자 사용)
- **앱 크기 · 첫 실행 시간**이 늘어남 (Unity 엔진 자체가 수십 MB)
- **전투 규칙을 C# 로 다시 써야 함**: `battle_rules.dart` 만 2,767줄, 규칙 폴더 전체 약 2만 4천 줄
- 빌드 · 서명 · 스토어 올리기 과정을 Unity 쪽으로 새로 잡아야 함 (TestFlight 흐름 포함)

## 걸리는 시간 (대략, 한 명 + Claude 기준)

| 길 | 내용 | 시간 |
|---|---|---|
| A. 전부 Unity 로 | 모든 화면 · 규칙 · 지도 · 카메라 · 로그인 · 광고 다시 만들기 | **6~10개월** (지도 · 카메라 대체가 가장 불확실) |
| B. 전투만 Unity, 나머지는 Flutter | Flutter 앱 안에 Unity 전투 화면을 끼워 넣기(Unity as a Library). 전투 규칙 C# 이전 + 서로 주고받는 연결 + iOS · Android 빌드 정리 | **5~8주** (연결 · 빌드가 까다로움, 앱 크기 증가) |
| C. Flutter 에 남고 연출만 보강 | Flutter 의 셰이더(FragmentProgram) · Flame(게임 엔진) · Rive 로 번쩍임 · 살랑임 · 입자 추가 | **2~4주** |

## 제 의견

이 시험판을 재생해 보고 **움직임 차이가 확실히 크다면 B(전투만 Unity)**, 차이가 크지 않다면 **C(Flutter 보강)** 가 맞아 보입니다.
A(전부 옮기기)는 네이버 지도 · 카메라 기능 때문에 시간과 위험이 커서 권하지 않습니다.
비교할 때는 같은 휴대폰 크기에서 ① 공격 6칸 타격감 ② 숨쉬기 · 살랑임 ③ 피해 숫자 · 효과 겹침 ④ 2배 속도에서의 부드러움을 나란히 보시면 좋겠습니다.
