# 나중 작업 목록

지금 바로 하지 않고 미뤄 둔 일입니다. 순서는 중요도 순.

## 지도 (2026년 11월 8일 등록)

지도 화면 코드는 완성되어 자동 테스트를 통과했습니다. 아래는 **실제 휴대폰에서 지도를 띄우기 전에** 해야 할 일입니다.

- [ ] **네이버 지도 Client ID 발급** — 네이버 클라우드 플랫폼 대표 계정(사업자)에서 Maps 앱 등록, 패키지 이름 `kr.itso.isekai_reality` 입력. 절차는 [platform_setup.md](platform_setup.md#네이버-지도)
- [ ] **장소 좌표 확인** — 휴대폰으로 지도를 띄워 실제 위치와 맞추기. 특히 고잔역은 추정값 ([gojan_places.md](gojan_places.md))
- [ ] **음유시인의 극장 결정** — 안산문화예술의전당이 화랑유원지(제외 구역) 바로 옆. 넣을지, 넣는다면 제외 구역 경계를 어떻게 잡을지
- [ ] **여관(카페)·잡화상(편의점) 고르기** — 고잔동 안에서 실제 가게 선정
- [ ] **제외 구역 경계 다듬기** — 지금은 반경 700m 원. 실제 화랑유원지·4·16 생명안전공원 경계에 맞추기
- [ ] **지도 색감** — 네이버 Map Style Editor 로 컨셉 아트 색(짙은 남색·금색)에 맞춘 지도 스타일 만들기
- [ ] **위치기반서비스사업 신고** — 테스터 배포 전 (방송통신위원회)
- [ ] 탐험 칭호 3종 추가: 미궁의 문지기(두 역 모두 방문), 호수의 친구(호수공원 5번), 고잔동의 빛(50% 밝힘)

## 그 밖에

- [ ] 필드 몬스터가 차도·철로 위에 나오지 않게 하기 — 지금은 장소 주변과 지역 안 임의 지점. 도로 데이터(또는 직접 고른 안전 지점 목록)가 필요
- [ ] 그림자 나비는 밤에만, 극장 근처에 나오기 (극장 결정 후)
- [ ] 몬스터 도감 화면 (정화 기록은 이미 저장 중)

- [ ] 게임 제목 상표 검색(KIPRIS 9류·41류)과 변리사 확인
- [ ] 몬스터 일러스트 6종(잿빛 모습 + 정화된 모습)을 `assets/images/` 에 넣기 — 없으면 아이콘으로 대신 보입니다
